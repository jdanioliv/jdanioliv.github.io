What I learned, week by week

Weeks 0–2: C, compiling and arrays

Binary, static data types, compiling with clang, functions, loops, arrays in contiguous memory, command-line arguments (argc, argv) and basic cryptography.

Week 3: Algorithms and Big O

Linear vs. binary search, sorting algorithms (bubble sort, selection sort, merge sort), recursion and running time analysis (O(n), O(log n), Ω).

Weeks 4–5: Memory, pointers and data structures

Hexadecimal addresses, pointers in C, dynamic memory (malloc and free), finding leaks with Valgrind, linked lists, binary trees, hash tables and tries.

Week 6: Python

Moving to a high-level language: lists, dictionaries, list comprehensions, exceptions and fast text and data processing.

Week 7: SQL

Database schemas in SQLite, SELECT and JOIN queries, indexes, primary and foreign keys, and preventing SQL injection.

Weeks 8–9: HTML, CSS, JavaScript and Flask

HTTP (GET/POST), web apps with Flask, Jinja templates, user sessions and connecting a backend to a database.
