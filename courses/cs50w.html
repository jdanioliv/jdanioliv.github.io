Course outline

Lectures 0–2: HTML, CSS, Git and Python

Page structure and styling, version control with Git and the Python needed for the rest of the course.

Lectures 3–4: Django, SQL and models

Web apps with Django: routes, templates, forms, models, migrations and the database behind them.

Lectures 5–6: JavaScript and user interfaces

DOM, events, fetch and APIs, single-page apps and animations.

Lectures 7–8: Testing, CI/CD, scalability and security

Automated tests, continuous integration and deployment, scaling a site and common security problems.
